# 2026-11-20-002 实施记录（Agent Bash 侧车契约修复）

> 对应计划：[2026-11-20-002-Agent-Bash工具侧车契约修复计划](2026-11-20-002-Agent-Bash工具侧车契约修复计划.md)
> 日期：2026-11-20　状态：**已实施**（服务已重启加载新代码；真实模型 Run 未做）

## 1. 根因

默认开关翻转（未提交 ADR 0043）后 `piBashSidecar = true`，但侧车 `execute()` 自己 spawn 并返回 `{code,stdout,stderr}`，不满足 Pi SDK `BashOperations.exec` 契约（`onData(Buffer)` + `{ exitCode }`），也不透传 `signal/timeout/env`。结果所有 bash（含 npm）显示 `(no output) / Command exited with code undefined`。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `server/内核侧车.mjs` | 删除自建 spawn；`BashSidecarManager` 改为并发门 + 统计（total/failed/timeout/aborted/active/bytes），新增 `run(command, cwd, options, executor)` 与 `createSidecarBashOperations(manager, executor)`；abort 支持排队出队/槽位不泄漏；`onData` 始终提供，Buffer 原样透传；超时/取消/进程树/cwd/env 全部委托 executor |
| `server/agent.mjs` | 新增 `sidecarBash = createSidecarBashOperations(getBashSidecar(), localBash.exec.bind(localBash))`；sidecar 分支改走 `sidecarBash.exec(..., execOptions)`；`backgroundEnabled` 去掉 `!piBashSidecar`（恢复广告中的后台 bash） |
| `scripts/优化项综合验收.mjs` | U5 断言从旧 `{code,stdout}` 改为“适配器 + localBash”契约（onData/exitCode/timeout/abort/统计） |
| `scripts/内核侧车契约测试.mjs`（新增） | 10 个用例：SDK 工具端到端 echo、npm/node 版本、非零退出+stderr、timeout=秒、pre-abort、运行中 abort、排队 abort、并发峰值≤4、坏 cwd/空命令、agent 接线静态断言 |
| `package.json` | 新增 `test:sidecar-contract` |
