## 0. 用户口径（2026-11-20 截图，原文）

1. 「正在分析请求」组头摘要被截断（"——指雷…"），要求**滚动**展示（思考行的滚动预览已具备同款能力）；
2. 组头**字体跟思考（行）一样**；
3. 颜色分态：**只有正在运行**的命令/分析请求文字不是浅灰，**已运行过的为浅灰**；
4. **每轮的澄清**（过程旁白，如"我来查这张图为什么没出来：…"）要**对齐**（截图红箭头指向旁白与思考正文左缘的错位）。

## 2. 界面与操作怎么变（改前 → 改后，用户视角）

- **组头摘要**：改前 = 一行静态摘要，超 40 字截断成"…指雷…"；改后 = 运行中的组头像思考行预览一样**跑马灯滚动**显示完整摘要（上限放宽到 120 字），**运行结束后**停止滚动、回退浅灰省略号静态摘要。
- **组头字号**：改前 = 13px，与思考行头（12.5px）不同档；改后 = **12.5px 与思考行同档**（拍板点 1）。
- **颜色**：改前 = 已完成的澄清旁白一直是亮色，与思考正文分不开；改后 = **流式打字中的旁白保持亮色，打完/已运行过的旁白转浅灰 `--muted`**（补齐规范 §4 本来就有的要求）；组头分态维持现状（运行中亮、已结束浅灰）。
- **对齐**：改前 = 澄清旁白比思考/工具明细正文右移约 22px；改后 = **旁白左缘与思考/工具明细正文同轴**（22px 网格，即用户箭头指向的方向；拍板点 2）。

## 5. 不做清单

- 不改终态折叠条 `RunFoldBar`（截图顶部条是运行态组头，非终态折叠头）；
- 不给思考行引入运行/结束分色（维持 2026-11-18「不用颜色区分思考」口径；运行中的思考已有扫光 shimmer 区分）；
- 不动结论/终稿 14px `--text` 层级与 `.tl-list-replies`（`:not()` 守卫保持）；
- 不改 `groupLabel` 的活动动词/类别摘要生成算法（只放开截断上限）；
- 非 v3 基线渲染路径不动；
- 不动组头 33px 行高与左侧 12+16px 网格结构。

## 6. 拍板点（需用户确认）

1. **组头字号**：A. 12.5px 与思考行同档（推荐，即"字体跟思考一样"的直译）；B. 保持 13px 只改滚动与颜色。
2. **旁白对齐轴**：A. 对齐思考/工具明细正文（22px，你箭头指的方向，推荐）；B. 维持 44px 组头标签轴，把思考/工具明细右移到 44px（改动面更大，影响所有明细缩进）。
3. **已完成旁白灰度**：A. `--muted`（推荐，与思考正文完全一致）；B. `--dim`（更浅，但与思考正文拉开两档）。

> 本项修订说明：旁白缩进从 44px 改为 22px 是对计划 [2026-11-19-001](2026-11-19-001-实施记录.md)「旁白与组头标签同轴」的修订——当时的同轴目标是"标签轴"，实测用户读感是"正文轴"（思考/工具明细正文都在 22px 轴），按用户 2026-11-20 截图箭头定为准。

## 9. 风险与回滚

- marquee 在组头 flex 行内与「N 次」计数、行尾 chevron 共存：组头 label 已是 `flex: 1; min-width: 0`（12527 行），marquee 约束复用思考预览模式，风险低；
- 流式旁白亮色选择器依赖 TypewriterText 的实际 DOM 类名，实施时先验证再落规则（避免写出永不命中的选择器）；
- 回滚：三处 CSS + 一处 JSX + 一处 slice 全部单点可逆；无契约、无事件、无存储变更。
