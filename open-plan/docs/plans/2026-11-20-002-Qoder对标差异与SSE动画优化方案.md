## 1. 动画优化方案

### P1 流式期间动画降噪（D1，核心）

1. **tl-row-in 降档**：`--dur-slow`（320ms）→ `--dur-fast`（120ms）；`translateY(6px)` → `translateY(4px)`。Qoder「短时长 ≤350ms」允许 320，但流式高频插入场景 320ms 会叠加成持续翻腾——按「插入频率越高、时长越短」原则降档。
2. **防重播**：核对 `.tl-list.is-live > *` 命中面——仅对**新插入行**播放：插入用 CSS animation 天然只播一次（元素新建）；但 React key 稳定性需核对（TimelineRow 的 key 生成），避免重挂载重播（如发现 key 不稳，修 key 不修 CSS）。
3. **收尾态动画停止**：run 结束（is-live 移除）后不再有入场动画——既有行为，保持；历史回放不重播（DESIGN.md:317 既有规定）。

### P2 流式气泡高度预留（D2）

- `.msg.assistant`（流式中）加 `min-height` 预留一行（约 1.6em）+ 内容块 `content-visibility` 不动（避免布局面扩大）；首 token 后自然撑高，消除起步跳变。**只动 min-height，不做高度插值**（高度插值需测量，违背 transform/opacity 约束）。

### P3 低端机降级联动（D4）

- `visualEffectsOff`（OAW_VISUAL_EFFECTS_OFF，默认关）接进统一动效闸门：开启时视为 calm 档以上降级——tl-row-in/扫光等"运行态装饰动画"关闭，功能过渡（折叠）保留。落点：界面外观.js `isMotionReduced()` 扩展判定（读 flag 下发值，不新增 flag）。
- 不动背景模糊实现本身（属 Q-54 范畴，见 P4）。

### P4 模糊分层与抽屉进场（D3/D5，拍板选做，可拆独立批）

- **模糊分层令牌**（Q-54）：`--layer-blur-overlay: 2px / --layer-shadow-raised: 24px / --layer-sheen: 10px / --layer-base-opacity: 0.18`，只应用于运行中侧栏/抽屉/交互坞三处层级表达；登记 DESIGN 动效章。
- **抽屉进场规范**（Q-55）：`data-drawer-motion = slide | reveal` + `@starting-style` 渐进增强（不支持的浏览器自动无动画）；时长 --dur-base，曲线沿用 --ease-out（**不引入 Qoder 的自定义 cubic-bezier**——DESIGN 令牌制已统一，避免双令牌体系，见不做清单）。
- P2-13 消息级动作（D6）不在本批（交互功能非动画），如需要另立。

### 验收

1. 集成断言：styles.css 静态断言 tl-row-in 时长为 --dur-fast、流式气泡 min-height 存在；动效治理测试不转红（新/改类登记）。
2. `test:ui-smoke`、`test:session-leak`、`test:chat-timeline`、`npm run verify` 不回归；`test:motion` 通过。
3. reduced-motion 与 visualEffectsOff 两条降级路径各配一条断言（闸门口径）。
4. 人工目验清单（记录进实施记录）：流式插入行不持续翻腾、气泡起步不跳、calm/off/visualEffectsOff 三档落定。

### 不做清单

- 不引第三方动画库；不引入 Qoder 自定义 cubic-bezier 曲线（沿用 --ease-out 单令牌体系）；不做高度插值动画（违反 transform/opacity 约束）；不动 P1-18 服务端分片；不做消息级动作（P2-13）；不改跑马灯/扫光参数（本轮已有规范值）；不做皮肤引擎（Q-51 判定不引入）。

### 复用清单

- 复用：--dur-*/--ease-out 令牌、动效闸门（界面外观.js）、tl-row-in 既有动画、TextShimmer、visualEffectsOff 既有 flag、动效治理测试登记机制；**不新增**组件文件、不新增 flag。
