## 1. 缺陷一：切换串页（运行中气泡泄漏）

**探针环境**：本机 3002 服务、会话 A=01a1f463（echart 图表任务，run_11f285c6 运行中）、会话 B=01a1f456（已完成），client-2jc5ynvu / 工作区 D:\日常任务吧。A↔B 慢速 2 轮（6s 停留）+ 快速 3 轮（1.8s 停留）。

**关键输出节选**（探针原始输出，2026-11-19 23:30 前后）：

```
[B-baseline] msg=2 ... first: 帮我来写篇文字材料
[A-baseline(运行中)] msg=3 ... streaming=1
[B慢#1] msg=3 streaming=1 ... last: opencode-go/deepseek-v4.1-flash 11/19 23:32 正在分析请求
[B快#1] msg=3 streaming=1 ... last: 行业下行，能
✗ 异常 24 处（B 消息数 3 ≠ 基线 2、指纹不一致、A 的流式气泡出现在 B）
```

**归属判定**：泄漏文本「行业下行」「正在分析请求」在 A/B 两会话 JSONL（.规聚会话/）与 Run 目录（.oaw/runs/）中均不存在——是尚未落盘的 A 实时流式内容，证明为 A 泄漏而非 B 自身历史。B 的 23:12 已完成任务不可能产生 23:32 的阶段文案。

**根因定位**：client/src/components/ChatPanel.jsx 历史水合「保留流式气泡」合并（当时 L1722-1750）：水合 effect 先于线程切换 effect 提交，messagesRef.current 仍是上一会话消息，find(status==="streaming") 无会话归属校验。

## 2. 缺陷二：asku 提问卡切换后消失

**接口实测**（2026-11-19，本机 3002）：

```
GET /api/interactions?client=client-f98rrzln&thread=…            → {"interactions":[]}   ← 裸键（浏览器实际形态）
GET /api/interactions?client=client-f98rrzln::thread-0b99dd62…  → 1 条 open 交互        ← 全键
```

- 记录写侧 clientId=agentKey 全键（server/agent.mjs createInteraction 调用点），读侧裸键全等 → 恢复接口恒空。
- 客户端链路：ask_user 事件（最小载荷）→ mergeInteractionEvent → refreshInteractions()（GET 恒空）→ setInteractions([]) 冲掉实时卡。切会话/刷新/SSE 重连均触发冲刷。
- 僵尸证据：.oaw/interactions.json 存在 status=open、threadId=""、expiresAt=null 的 2026-09-28 记录（itx_0de4dfd1…），因 `!item.threadId` 分支可跨会话匹配。
