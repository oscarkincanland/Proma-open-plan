# 0043 新功能运行开关全部默认打开

- 状态：已采纳
- 记录日期：2026-11-19
- 决策者：用户（本轮对话直接指令：「新功能都默认打开」；在给出「用户可见新功能 / 全部 / 仅最新两大功能」三档范围选项后明确选择「全部默认打开」）
- 基线：v0.13.26（`develop @ 082301f1`，合并 origin/develop 15 项更新之后）
- 关联：取代 [0004 优化开关统一且默认关闭](0004-优化开关统一且默认关闭.md) 的「默认关闭」半边（统一管道语义不变）；`server/运行开关.mjs`；`docs/规范/运行时验收与门禁规范.md`

## 1. 背景

开关统一管道（ADR 0004）把全部优化项收进 `server/运行开关.mjs`：env > `.oaw/runtime-flags.json` > 代码默认值。此前按「默认关 = 与基线逐字一致」的原则，约 64 个功能开关出厂即关（创作画布、会话流 v3、领域工作流、2026-11-08 交互/写作族、Qoder/Harness/BrowserAtomic 三族、GIS 外部适配器等），实际使用依赖用户手开 env 或配置文件。

产品已进入稳定版收尾：新功能大多已完成全量回归与验收（2026-11-17-001），继续默认关会让单机用户默认拿不到能力。用户在稳定版预发布阶段明确拍板：**全部默认打开**，含 Qoder 换肤、H 线仪表化、外部数据适配器、浏览器原子族。

## 2. 决策

1. `server/运行开关.mjs` 中除降级开关 `OAW_VISUAL_EFFECTS_OFF` 外，全部功能开关改为 `readFlagDefault(name, true)`：Qoder/Harness/BrowserAtomic 三个族总开关默认开，族内单项随族默认开。
2. 优先级语义不变：环境变量与 `.oaw/runtime-flags.json` 仍可显式 `0/false/off` 关闭回退；`readFlagDefault` 的 env FALSY 分支保留。
3. `OAW_VISUAL_EFFECTS_OFF` 是「视觉特效降级」开关（开启=去特效），不是功能开关，保持默认关。
4. 守护测试同步：`test:gis-flags`（外部适配默认开）、`test:runtime-flags-file`（缺文件/坏文件回落默认值=开）按新策略更新断言；其余受影响基线以全量回归为准修齐。

## 3. 影响

- 单机/桌面端用户开箱即得全部已实现能力（创作画布、会话流 v3、领域工作流、统一交互中枢、一次成稿、Qoder 视觉层等）。
- 服务行为面显著变大：H 线仪表化族（记忆抽取、Hook 事件、错误 envelope 等）进入默认链路；Qoder 开启后整站换肤。已知风险（如长会话流式渲染崩溃等 2026-11-18 复盘遗留）由验收记录跟踪，不因本决策扩大范围。
- 回滚路径：任一开关 env/配置文件显式置 0；整体回退可用 `OAW_QODER_ALIGN=0 OAW_HARNESS_ALIGN=0 OAW_BROWSER_ATOMIC=0` 三键。

## 4. 后续

- 稳定版发布说明需列出「默认开启清单」与三键回退方法。
- 新增开关一律走运行开关管道；是否默认开按「已过全量回归 + 有守护测试」判断，不再一律默认关。
