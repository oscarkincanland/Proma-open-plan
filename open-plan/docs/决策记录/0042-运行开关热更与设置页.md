# 0042 运行开关热更与设置页

- 状态：已采纳
- 记录日期：2026-11-19
- 决策者：用户（方案 [2026-11-19-002](../plans/2026-11-19-002-运行开关设置页与热更方案.md) 确认；拍板点 1–5 均按推荐项 A 执行，另明确「做好开关设置界面的端到端测试」）
- 基线：v0.13.26（develop）
- 关联：取代 [0004 优化开关统一且默认关闭](0004-优化开关统一且默认关闭.md) 的「启动时解析一次、不热更」半边（管道统一与优先级语义保留）；[0040 新功能运行开关全部默认打开](0040-新功能运行开关全部默认打开.md)；`server/运行开关.mjs`；[方案 2026-11-19-002](../plans/2026-11-19-002-运行开关设置页与热更方案.md)（含两轮对抗审查记录）

## 1. 背景

运行开关管道（ADR 0004）把约 90 个开关收进 `server/运行开关.mjs`，快照在模块加载期一次性求值、进程内不热更，修改只能设环境变量或手编 `.oaw/runtime-flags.json` 并重启服务。产品进入稳定版收尾后，用户要求：设置界面可切换运行开关、保存后热更即时生效（不重启）、只暴露用户可感知开关、明确提示环境变量与配置文件的来源冲突，并做好设置界面的端到端测试。

## 2. 决策

1. **热更管道**：`RUNTIME_FLAGS` 从加载期 `const` 改为 `buildRuntimeFlags()` 构建 + `export let` 绑定 + `reloadRuntimeFlags()` 热更入口（重置持久化缓存 memo 后重建）。优先级语义不变：**环境变量 > `.oaw/runtime-flags.json` > 代码默认值**。
2. **加载期求值点函数化**（热可达性）：`task.mjs` 四份工具白名单的 flag 条件段移入 `toolPolicyForMode` 调用期求值（集合成员逐字不变）；`workspace.mjs` CAD 扩展段、`context.mjs` 文档支持集改函数。例外：`index.mjs` 外部数据适配器注册是模块级动态 import、无法运行中卸载，`dataAdapters` 标注 `restartRequired`（写盘生效、重启后生效）。
3. **设置页白名单**：`USER_EDITABLE_FLAGS` 定义在 `运行开关.mjs`（唯一事实源），常用 17 项默认展开、高级 25 项折叠；数值调参、域名白名单、`feedbackV2`、三族族内单项不进设置页。护栏与族总开关关闭需应用内二次确认；`visualEffectsOff`/`runBudgetUnlimited` 为反向语义并单独标注。
4. **API 与事件**：`GET/POST /api/runtime-flags`（白名单校验、env 接管键跳过写盘并标注 `envLocked`、临时文件 + rename 原子写、失败不 reload 不广播返 500）；事件 `runtime_flags_changed`（lifecycle + persist，携带发起页 clientId，`data.flags` 为 reload 后全量生效快照），同 client 其他标签页实时同步，新页面经 `/api/status` 兜底。
5. **前端通道**：`client/src/运行开关.js` 新增 `applyRuntimeFlagsSnapshot`（整体替换快照 + 版本号）与 `useRuntimeFlagsVersion` 订阅；App 全局事件流接线；ChatPanel 两处 mount 期接线改为随版本号重接。
6. **transcriptV3 口径对齐**：该开关保持默认开（ADR 0043 已定，2026-11-19 复核确认）且常驻设置页可切换；《会话流渲染通道清单》中「开关最终移除」的时点调整为「设置页移除时一并移除」，C3/C4/C5 基线通道在开关可关期间继续保留。

## 3. 影响

- 用户可在设置页直接切换约 42 个功能开关，保存即生效，无需重启；被环境变量接管的开关锁定并提示。
- 运行中任务的语义边界：任务创建时快照项（白名单、runBudget）当轮不变；逐次读取项（如 `writingOneShot`）下轮调用即生效——由热更测试显式断言。
- 新增公开 API `GET/POST /api/runtime-flags` 与事件 `runtime_flags_changed`（已登记事件注册表，契约测试守护）。
- 新增测试：`test:flags-e2e`（端到端判据 1–10）、`scripts/运行开关热更测试.mjs`、`scripts/运行开关API契约测试.mjs`；`test:ui-smoke` 扩展功能开关分区冒烟。

## 4. 回滚

- 整体 revert 本组提交即回到「改配置文件 + 重启」的旧语义；`.oaw/runtime-flags.json` 手工清理后重启即回到基线。
- 单开关回退：设置页切回，或 env/配置文件显式置值（优先级不变）。
